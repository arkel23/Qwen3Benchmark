This repository is missing `pong/classes.py`. Write that file so `scripts/probe_sufficiency.py` and
`scripts/identifiability.py` run unchanged and reproduce the numbers recorded in `FINDINGS.md`.

Read `README.md`, `FINDINGS.md`, both scripts, `pong/sim.py` and `pong/rules.py` first: the scripts
show every function they import and how they call it.

The file must provide:

- `probe_actions(ticks=256, controlled=32, random=32, seed=0)`: one fixed set of open-loop action
  sequences `(controlled + random, ticks)`, the same for every program. The controlled half is
  actions recorded by the scripted controller on randomly chosen programs; the random half is drawn
  uniformly from `{-1, 0, 1}`. The result depends only on the arguments.
- `replay_all(programs, actions)`: visible trajectories `(P, A, T + 1, 4)` of every program under
  every action sequence, using one batched `simulate` call rather than a Python loop per program.
- `equivalence_classes(programs, actions)`: a class id per program, ids numbered by first occurrence
  in `programs`, where two programs share an id exactly when their trajectories under `actions` are
  identical.
- `consistent_programs(programs, seen_actions, seen_visible)`: a boolean mask over `programs`,
  true where the program reproduces `seen_visible` `(K, T + 1, 4)` under `seen_actions` `(K, T)`.

Two programs are equivalent when they produce the same visible trajectories under every probe
action sequence.

Follow the repository's own conventions. Create the file and stop; do not change anything else.
