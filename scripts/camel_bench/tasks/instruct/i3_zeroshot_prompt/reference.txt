Previous work shows that the prompt matters for LALMs. Burdisso et al.\ \cite{burdisso_reducing_2026} vary prompt wording within one language and find the choice matters. AlignFormer \cite{fan_alignformer_2025} reaches zero-shot instruction following by replacing the projector and modifying the audio-instruction order at training time. Inspired by this, we ask whether the prompt alone, with no retraining, can repair LA. Changing only the prompt increases LA to \BestAdherencePct{}.
